# Research2 Directional Backtest Methodology

这份文档记录当前 `research-2` 七态系统的第一版方向回测方法，目的是为后续“数据量更大时的正式回测”保留统一口径。

当前结论只作为方法验证，不作为正式策略结论。核心原因是：

- 当前有效交易样本仍然偏少
- `8-4-7.8-40` 下的方向交易信号还不够多
- 周线级别回测天然样本慢

## 1. 当前研究目标

当前不是回测“七态标签本身是否正确”，而是回测：

- 当 `research-2` 在指定参数下出现新的方向家族信号时
- 如果顺着新家族方向做多或做空
- 在固定止盈和不同止损规则下
- 最终盈亏表现如何

当前只关心 3 个家族：

- `Bull`：绿
- `Bear`：红
- `Sideways`：灰

## 2. 当前采用的分段参数

当前方向回测优先使用：

- `minSegmentWeeks = 8`
- `latestSegmentMinWeeks = 4`
- `splitPenalty = 7.8`
- `maxSegmentWeeks = 40`

选择原因：

- 这组参数在当前家族级回测里，新家族延续率较高
- 它比 `8-5-7.8-40` 更偏确认，而不是更偏早期试探

## 3. 信号定义

当前方向回测只使用“新家族明确有方向”的信号：

- `Sideways -> Bull`
- `Bear -> Bull`
- `Sideways -> Bear`
- `Bull -> Bear`

不直接交易：

- `Bull -> Sideways`
- `Bear -> Sideways`

原因：

- 这两类更接近“趋势减弱 / 进入灰区”
- 它们更适合做风控和降仓，而不是直接做方向入场

## 4. 入场规则

当前口径：

- 当某一周收盘后，`research-2` 重新计算，确认最新家族变为 `Bull` 或 `Bear`
- 在下一周开盘价入场

具体执行：

- `Bull` 信号：做多
- `Bear` 信号：做空

## 5. 出场规则

当前固定：

- 止盈使用 `1 : 1.5`

当前候选止损规则分为两类。

### 5.1 固定百分比止损

扫描区间：

- `2.0%`
- `2.5%`
- `3.0%`
- `3.5%`
- `4.0%`
- `4.5%`
- `5.0%`
- `5.5%`
- `6.0%`
- `6.5%`
- `7.0%`
- `7.5%`
- `8.0%`
- `8.5%`
- `9.0%`
- `9.5%`
- `10.0%`

### 5.2 结构止损

候选包括：

- `signal_week_extreme`
  - 做多：信号周最低点
  - 做空：信号周最高点
- `segment_extreme`
  - 做多：最新方向段的最低点
  - 做空：最新方向段的最高点
- `ema21_anchor`
  - 做多：信号周 `EMA21`
  - 做空：信号周 `EMA21`

## 6. 持仓切换规则

当前方向回测为单仓模型：

- 同一时间只持有一笔仓位
- 如果还没触发止盈或止损，但新的方向信号出现
- 则在下一个方向信号开盘时平掉旧单并切换

这条规则的目标是：

- 让回测更接近“只跟随当前最新方向家族”
- 避免长期死扛

## 7. 周线内触发顺序规则

当前采用保守处理：

- 如果同一根周 K 同时覆盖止盈和止损
- 一律按“先止损”处理

原因：

- 周线数据没有日内顺序
- 先按不利方向算，更稳妥

## 8. 当前回测口径

当前每笔按固定名义本金：

- `1000U`

盈亏计算：

- 不加杠杆
- 不考虑手续费
- 不考虑滑点

这是一个最基础的净方向模型，后续正式回测应补：

- 手续费
- 滑点
- 真实可成交性
- 资金利用率

## 9. 当前样本下的暂时观察

在当前小样本下，初步观察到：

- `EMA21` 结构止损优于多数固定百分比止损
- 固定百分比里，较宽止损明显优于过窄止损
- 当前最好的固定止损大致落在 `9.0% - 9.5%`
- `Bull/Bear` 新家族信号本身不多，因此结论还不能视为稳定

这些观察只说明：

- 当前方法链路可跑通
- 当前策略对止损定义比较敏感

不说明：

- 这套参数已经足够实盘
- 现在的最佳止损已经稳定

## 10. 后续正式回测时必须扩充的内容

### 10.1 数据扩充

后续需要尽量扩充：

- 更长的 BTC 周线历史
- 更完整的 funding / volume 历史
- 如果可能，再加入其他大市值标的做横向验证

### 10.2 分组回测

后续正式回测必须拆开看：

- `Sideways -> Bull`
- `Sideways -> Bear`
- `Bear -> Bull`
- `Bull -> Bear`

不要只看总收益。

### 10.3 止损微调

下一阶段重点不是再扫更大区间的固定百分比，而是细化结构止损：

- `EMA21`
- `EMA21 - 0.5%`
- `EMA21 - 1.0%`
- `EMA21 - 1.5%`

做空侧对应：

- `EMA21 + 0.5%`
- `EMA21 + 1.0%`
- `EMA21 + 1.5%`

### 10.4 过滤条件

后续可加入过滤器再测：

- `ADX`
- `BBW`
- `ReturnZ`
- `segment positive share`
- `segment slope`

目标不是让信号更多，而是筛掉低质量方向切换。

## 12. 当前建议

在样本还少的时候，后续工作优先级应是：

1. 继续完善七态程序和指标体系
2. 继续累积更多历史样本
3. 保留当前回测脚本和方法口径
4. 等样本足够后，再做正式的方向策略筛选

当前不建议基于这一版小样本直接定实盘止损规则。
